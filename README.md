# LSE Members Interface

Interfaccia web React per visualizzare e gestire l'elenco dei membri dell'organizzazione LSE, con integrazione Discord e API RSI di Star Citizen.

## Avvio rapido

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

## Note
- **Docker**: non usato nel progetto (rimosso).
- **Config**: vedi `.env.example` e `backend/.env` (non committare segreti).
